## What Run 02 contributed

Run 02 corrected an earlier invalid assumption that one Owner play session could validate everything.

It separated two important evidence questions:

### Game truth

Is the Tysiąc implementation correct, credible and authentic enough for knowledgeable play?

Evidence sources established here included:

- fresh rule/source research;
- reference implementation probes where feasible;
- explicit reversible project pins;
- executable scenarios, invariants and deterministic simulations;
- knowledgeable Tysiąc-player/domain sessions for strategy/authenticity.

The Owner is not the rule/strategy oracle.

### Experience truth

Is the table clear, responsive, satisfying and progressively professional on desktop and mobile?

The Owner is primary judgement source for visual hierarchy, interaction/touch feel, feedback, perceived pacing, responsive composition, onboarding and overall presentation quality.

Automation may defend measurable mechanics but cannot certify taste or fun.

## Important later extension

The 2026-09-15 friend-link incident showed that two evidence tracks were insufficient for project governance.

The project now recognizes a third independent class:

### Operations / external truth

Questions include:

- temporary or account-owned/non-temporary deployment?
- what exact candidate SHA is actually public?
- does the real copied invite work?
- does the same origin/SHA remain available later without redeploy?
- can a real second human use it?

A green game-truth or experience-mechanics result cannot substitute for an operations/external failure.
