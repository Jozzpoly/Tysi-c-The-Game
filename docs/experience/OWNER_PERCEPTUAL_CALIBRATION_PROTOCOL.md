# Owner perceptual calibration protocol

Status: research method candidate. This is not a requirement to turn Owner testing into a formal lab study.

## Purpose

The project has one unusually important source of perceptual/product evidence: the Owner.

That is a strength, but it creates methodological risks:

- novelty bias;
- order effects;
- adaptation to earlier mappings;
- expectation from names/descriptions;
- fatigue;
- trying to please the experiment rather than naturally use the object;
- over-interpreting one preference as universal truth.

The goal is not to simulate population science with one participant. The goal is to make each Owner test **more information-dense and less biased** while preserving natural reactions.

## 1. Two evidence modes

### Mode A — natural first contact

Use when the question concerns:

- discoverability;
- spontaneous manipulation;
- salience;
- comprehension;
- overall character;
- whether the interaction invites play/exploration.

Rules:

- minimal explanation;
- no priming with intended mechanism;
- neutral naming;
- preserve raw language;
- record what is touched/ignored before asking analytical questions.

This remains the primary product-experience mode.

### Mode B — perceptual calibration

Use only after natural behavior exposes a specific uncertain variable.

Examples:

- how much control/display discrepancy becomes noticeable or intrusive;
- when fixed card offset stops feeling attached to the finger;
- how much neighbor displacement is perceivable before it becomes noisy;
- minimum difference in rotational response that produces a distinct material impression;
- where assistance changes from helpful to ownership-stealing.

This mode can use psychophysics-inspired procedures.

## 2. Pairwise comparison before numeric rating

When comparing subtle interaction variants, prefer questions such as:

- Which felt more directly under your control?
- Which felt heavier?
- Which was easier to place precisely?
- Which would you rather use repeatedly?
- Did these feel meaningfully different at all?

Pairwise choice is often cognitively simpler than assigning independent 1–10 scores and avoids some personal scale-normalization problems.

Do **not** ask all questions every trial. Match the question to the variable being investigated.

## 3. Neutral candidate identity

Never present experimental names such as:

- `PREMIUM`;
- `WEIGHT`;
- `REALISTIC`;
- `NEW`;
- `PRO`;
- `MAGNETIC SMART`.

Such labels frame expectations.

Use neutral identifiers such as:

`A / B`, `1 / 2`, or randomized anonymous variants.

Even `baseline` may bias judgement if the Owner knows which variant it is.

## 4. Randomize order when the comparison allows it

Order matters because:

- visuomotor adaptation changes later perception/control;
- novelty affects subjective preference;
- the first candidate establishes a reference frame;
- fatigue can punish later candidates.

For an Owner study we cannot achieve population counterbalancing, but we can:

- randomize pair order;
- sometimes repeat the same pair in reverse;
- include occasional identical/near-identical checks;
- record exact order;
- separate first-contact preference from later repeated-use preference.

## 5. Identical / sham comparison as a bias detector

Occasionally two labeled variants may intentionally use the same underlying parameters.

Purpose:

- detect how much expectation/order/noise is influencing judgement;
- remind us not to over-interpret tiny subjective differences.

This should be used sparingly. The Owner should not be forced into endless trick questions.

## 6. Adaptive threshold search

For one scalar perceptual variable, an adaptive staircase can be useful.

Example research question:

> At what acceleration-sensitive position discrepancy does a card stop feeling fully attached to my movement?

A lightweight staircase could:

1. begin with an obviously distinguishable level;
2. reduce distortion after it is judged intrusive/distinct;
3. increase it after it is judged indistinguishable/non-intrusive;
4. reverse direction around the boundary;
5. shrink step size after reversals;
6. stop after enough stable reversals to identify an approximate individual region.

This is not intended to produce a publication-quality JND.

The useful output is an Owner-specific **working perceptual band** such as:

- below this region: no meaningful added character;
- middle region: material effect visible but ownership retained;
- above this region: interference becomes obvious.

## 7. Method of constant stimuli for high-value variables

For variables strongly affected by expectation, a small set of fixed values can be presented in randomized order.

This avoids the obvious directional pattern of a staircase.

It is more trial-expensive, so reserve it for high-value questions where adaptation and anticipation would otherwise dominate.

## 8. Preference threshold is not detection threshold

The Owner may detect a difference long before it matters positively or negatively.

Separate questions:

### Detection

`Do these feel different?`

### Attribution

`What feels different?`

### Tolerance

`At what point does this start bothering you?`

### Preference

`Which would you rather use?`

### Repetition

`Which would you rather use 100 times?`

These thresholds can be very different.

A useful donor concept may be closer to a **Just Tolerable Difference** or preferred operating band than a classic sensory JND.

## 9. Preserve raw natural language

Do not replace statements such as:

- `to się klei`;
- `martwe`;
- `odjeżdża mi`;
- `jakby lagowało`;
- `to już nie jest moja karta`;
- `to jest zajebiście miękkie`;
- `nie chce mi się tym ruszać`;

with only a technical tag.

Record:

1. exact statement;
2. exact variant and task;
3. what the Owner was doing immediately before it;
4. technical interpretation separately.

Natural metaphor can reveal perceptual structure that our taxonomy missed.

## 10. Behavior can outrank stated preference

If the Owner says `A is better` but repeatedly:

- fidgets more with B;
- makes fewer corrective movements with B;
- chooses B when not asked;
- abandons A sooner;

that discrepancy is important evidence.

Do not automatically decide that behavior is `truer`; investigate the conflict.

Possible explanation:

- A looks/feels more impressive;
- B is easier to live with;
- one optimizes first impression, the other repetition;
- novelty or framing affected the explicit choice.

## 11. Separate first impression from endurance

A candidate can be:

- impressive for 20 seconds;
- pleasant for 5 minutes;
- annoying after 50 repetitions.

Record at least conceptually:

`first-contact -> short repeated use -> torture/repetition -> return-after-break`

Do not ask the Owner to perform all phases every time.

## 12. Adaptation and switch-cost evidence

When comparing transformed control laws, inspect what happens immediately after switching variants.

Useful observations:

- overshoot after switching to higher/lower gain;
- temporary correction bursts;
- movement hesitation;
- trajectory changes;
- verbal reaction such as `this suddenly flies` or `this drags`.

These can indicate adaptation to the previous mapping.

Therefore later steady-state performance must not be interpreted in isolation.

## 13. Single-owner experimental limits

This protocol can support:

- calibration to Owner taste/body;
- within-person discrimination of mechanisms;
- finding useful parameter regions;
- explaining raw feedback;
- selecting candidates for product exploration.

It cannot establish:

- population preference;
- accessibility for diverse motor abilities;
- universal perceptual thresholds;
- statistical generality;
- novice comprehension across user groups.

Later public/product validation will need broader users if the game reaches that stage.

## 14. Protect Owner attention

Calibration is only justified when it answers a question that cannot be resolved mechanically or conceptually.

Before requesting Owner trials:

- reject unstable candidates internally;
- minimize variants;
- make labels neutral;
- remove obvious jank;
- predefine what difference would change the design decision;
- stop when evidence is sufficient.

Do not turn the Owner into an unpaid psychophysics machine.

## 15. Proposed future use in Card Embodiment

Not yet authorized for implementation.

Potential future sequence:

1. natural blind first-contact among a very small number of mechanically stable control laws;
2. paired comparison on agency/materiality/repeated-use preference;
3. only if a parameter boundary remains important, adaptive calibration around that one dimension;
4. repeated-use torture with the surviving region;
5. minimal hand-context retest to detect loss of ecological validity.

## 16. Donor value

The same method can calibrate:

- JV gizmo resistance/snap;
- Multi World manipulation assistance;
- JES brush/constraint feedback;
- animation/transition timings;
- haptic/audio intensity bands;
- AI assistance thresholds where more automation may steal agency.

The donor is not a fixed staircase implementation. It is the discipline of **using Owner perception as a calibrated measurement instrument without pretending one person is a population study**.

## External methodological anchors

- psychophysical method of adjustment, limits and constant stimuli;
- adaptive staircase procedures;
- paired comparison methods;
- JND versus tolerable/preferred ranges;
- within-subject order/counterbalancing practice;
- novelty-bias evidence in interactive prototype evaluation.
