# Experience Foundation — canonical state

This is the compact source of truth for Run 03.

Tysiac is being used as a bounded laboratory for a broader Owner priority: **living, embodied, causally truthful, high-quality interaction and interface design** that may later donate knowledge into other projects.

Progress is measured by reduced uncertainty and better design decisions, not document/commit count.

## Owner target

Preserve these requirements:

- cards should feel like manipulable objects, not buttons;
- the private hand should be an exceptionally rich, user-owned workspace;
- manual ordering/rearrangement matters;
- routine play should teach through visual/behavioral language rather than banner-heavy tutorialing;
- feedback should feel alive and materially responsive without lying about authority/state;
- mobile and desktop are equally serious long-term targets;
- truthful interaction is necessary but sterile `correct UX` is still failure;
- product character, visual hierarchy, motion, sound, optional haptics, rhythm and consequence belong to the same system;
- substantial internal analysis/falsification should happen before another Owner test;
- Tysiac-specific excellence comes first; donor abstraction happens only after evidence.

## Current verdict

Run 03 remains **directionally correct** after Owner-alignment audit.

The previous imbalance toward low-level methodology has been corrected. Current work is now organized across four coupled disciplines:

1. **Interaction truth** — authority, causality, constraint provenance, recovery;
2. **Embodied control + workspace** — card control, hand field, personal topology;
3. **Experience character + sensory composition** — visual/motion/audio/haptic/typographic character and dynamic range;
4. **Gameplay dramaturgy + attention** — scenes, opponent/action-source presence, persistent consequence, initiative and rhythm.

Production gameplay/core and production `GameTable` remain unchanged.

## Capability layering

A major synthesis finding:

> operation-specific illegality should not erase unrelated object capabilities.

`not legal to play` does not imply `disabled object`.

A card can remain:

- owned;
- inspectable;
- reorderable;
- groupable;
- reversibly manipulable;

while `play(card -> trick)` is currently domain-illegal.

This is now part of `CONSTRAINT_SEMANTICS_AND_RECOVERY.md` and is a strong donor candidate, still unproven by Owner evidence.

## First Living Slice — selected INTERNAL synthesis target

Status: **INTERNAL DESIGN TARGET SELECTED; not Owner-ready**.

Situation:

> local player closes a trick with the third card from a living private hand; the accepted play resolves the trick, transfers ownership/value and establishes next initiative.

Why this slice:

It combines Card Control, Hand Workspace, legality, progressive intent, commit, authority, opponent action source, scene composition, collection, points, persistent consequence, sensory dynamic range and mobile/desktop embodiment in one common repeatable action.

See `FIRST_LIVING_SLICE.md`.

## Living Slice semantic chain

`private hand -> reversible manipulation -> play relation -> commit -> authority -> card arrival -> trick closure -> winner/ownership -> collection -> point consequence -> next initiative -> settle`

`card-played` and `trick-completed` remain truth atoms but should form one perceptual scene when they belong to the same causal event.

## Authority / presentation seam

Current remote runtime correctly receives `SeatProjection + GameEvent[]`, but applies after-state immediately and then holds input using fixed playback delays.

Future experience layer should preserve authority while avoiding perceptual teleportation through:

- **authoritative projection** — canonical viewer-safe truth;
- **presented stable projection** — stable situation the player has perceptually reached;
- **ephemeral transition layer** — non-authoritative objects/relations carrying identity between before and after.

Conceptual input:

`presented before + viewer-safe events + authoritative after -> experience transition`

Current authority always wins. Reconnect discards stale transient choreography rather than replaying history.

See `TEMPORAL_INTEGRITY_AND_AUTHORITY.md`.

Rules:

- sound/haptics enhance but do not carry exclusive rule truth;
- common trick closure does not spend maximum intensity;

- illegal relation does not make the card itself dead;
- sound-off, no-haptic and reduced-motion remain first-class conditions.

## Experience Character state

Status: **RESEARCH ACTIVE; still a major gap**.

Known Owner taste boundaries are preserved as evidence, not final art direction:

Avoid defaulting to felt/poker-table identity, wood/leather skeuomorphism, fantasy CCG language, old-web/Kurnik presentation, sterile SaaS/dashboard composition or generic dark-glass/glow premium styling.

Current positive direction: modern digital-first presentation where UI serves cards/actions, physical intuition supports control, and feedback itself becomes gameplay language.

## Self-teaching target

Not `zero text`; not `hide complexity`.

Working sequence:

`affordance -> feedforward -> safe reversible probing -> meaningful constraint -> local feedback -> explicit explanation when useful`

Embody causal/spatial operations strongly. Explain arbitrary conventions honestly rather than faking physical laws. Never confuse strategic mistake with illegality.
