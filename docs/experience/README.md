# Experience track

This directory captures durable presentation/UX research for **Tysiąc The Game**.

The project separates two evidence streams:

- **game truth** — rules, legality, scoring, networking, privacy and canonical state;
- **experience truth** — clarity, interaction feel, visual hierarchy, timing, feedback, motion, audio/haptics, mobile/desktop ergonomics and professional impression.

The Owner is the primary judge of experience truth. Owner experience feedback is not used as proof of Tysiąc rule authenticity or bot strategy quality.

Current documents:

- `UX_FEEDBACK_GRAMMAR.md` — action -> reaction -> consequence language;
- `EXPERIENCE_ORCHESTRATION.md` — event response matrix and sensory hierarchy;
- `EXPERIENCE_ARCHITECTURE.md` — presentation-only choreography seam over existing `GameEvent[]` + `SeatProjection` authority.

Exploratory executable fixtures live under `lab/experience/` and are not production gameplay authority.
