## What changed in our understanding

**1. Experimental authority is real, not rhetorical.** On 18 Sep, Owner saw an apparent card-speed regression and believed the project had lost the accepted state. Investigations separated branch SHA, deployed Worker SHA, and JavaScript already executing in a previously loaded browser tab. The tested B0/B1/B2 automatic trick timing was equivalent; stale client was a plausible explanation, *not proven for that historical browser*. #61 Golden must remain a control until fresh Owner observation promotes a candidate. This is why #75 came directly off the Golden product, not the newer `main` UI.

**2. A red CI run is a question.** The desktop handoff test failed twice on main even with correct presentation; later trace showed an approximately 25ms transient marker, invisible to WebDriver's coarse polling. Forensics [#69](https://github.com/Jozzpoly/Tysi-c-The-Game/pull/69) and durable observer [#74](https://github.com/Jozzpoly/Tysi-c-The-Game/pull/74) distinguish actual movement from sampling failure without weakening target/revision/no-duplicate requirements. Another docs-only failure required an obsolete September phrase; the current authority and verbatim archived forensics now receive separate test assertions.

**3. Hidden cards and seat continuity are material multiplayer properties.** Error handling previously erased a valid local seat token for ordinary transport outages — fixed by merged [#72](https://github.com/Jozzpoly/Tysi-c-The-Game/pull/72) with failed-request injection. Public deterministic 32-bit seed enabled practical offline hidden-deal narrowing despite server-private projections — fixed by merged [#73](https://github.com/Jozzpoly/Tysi-c-The-Game/pull/73) with crypto-shuffled server-only decks for initial/next-hand/four-nines deals. **Both fixes are not serving on current Golden**, and old current hands are not retroactively shuffled. Issues [#70](https://github.com/Jozzpoly/Tysi-c-The-Game/issues/70) and [#71](https://github.com/Jozzpoly/Tysi-c-The-Game/issues/71) correctly remain open as public release gates.

**4. Integration should follow the user's journey, not a shared architecture diagram.** Opus had already solved the launcher issue in Jaskinia. The missing capability was in Tysiąc: occupied seat authority survived in same-origin localStorage, but revisiting the game's root offered no way to reach that table. #76 uses that existing capability and handles legacy Golden tokens; it doesn't send private tokens to Jaskinia or Medium. Machine tests cover 390px mobile re-entry, history, reload, same-seat token, negative no-token case, physical hand and source-checkout marker. **Real phone and real friend experience are still untested.** A local Jaskinia note isn't a shared Medium record by magic.

**5. The Worker stayed on Golden. Credential normalizer gave us a conclusive external blocker: **the existing GitHub Cloudflare token is expired**.
